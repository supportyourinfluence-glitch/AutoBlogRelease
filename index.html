다운로드한 프로그램은 구독 계정으로 로그인해야 동작합니다. 아래 이용 전 확인을 꼭 읽어주세요.

주요 기능

키워드 추천

실시간 트렌드와 쇼핑 인사이트를 모아 후보를 제안합니다. 직접 입력할 수도 있습니다.

초안 자동 작성

선택한 키워드로 본문을 생성하고, 문단마다 관련 이미지를 한 장씩 넣습니다.

예약 발행

최소 30분 간격으로 순차 예약합니다. 발행 이력에서 결과를 확인할 수 있습니다.

내 PC에서 실행

글 내용과 계정 정보는 사용자 PC에 저장됩니다. 서버는 계정·이용권만 관리합니다.

이용 전 반드시 확인

  • 네이버는 자동 게시를 약관으로 제한합니다. 어뷰징으로 탐지되면 계정이 제재될 수 있으며, 그 책임은 이용자 본인에게 있습니다. 하루 3~5회 이내 사용을 권장합니다.
  • 예약 발행은 이용자 PC가 켜져 있고 프로그램이 실행 중일 때만 동작합니다.
  • 삽입되는 이미지는 검색 결과이며 제3자 저작권 대상일 수 있습니다. 발행 전 확인이 필요합니다.
  • AI 글 생성 비용은 이용자 본인 부담입니다(본인 API 키 사용).

시작하기

  1. 구독 결제하고 계정 만들기

    결제 화면에서 이메일·비밀번호로 가입한 뒤 카드를 등록합니다. 카드 정보는 결제대행사가 처리하며 저희 서버에 저장되지 않습니다.

  2. 프로그램 내려받아 설치하기

    Windows용 실행 파일 하나로 동작합니다. 설치 후 위에서 만든 계정으로 로그인하면 구독이 확인됩니다.

  3. 네이버 로그인과 API 키 연결하기

    프로그램의 "연결" 화면에서 네이버에 로그인하고 본인 API 키를 입력하면 키워드 추천부터 예약 발행까지 바로 사용할 수 있습니다.
